Travel Explore – UI/UX Design

About the Project

Travel Explore is a UI/UX design project created to provide users with a simple and convenient way to explore travel destinations.

The design focuses on easy navigation, destination discovery, and a user-friendly travel experience.

Objectives

- Provide an easy-to-use travel exploration interface
- Help users discover different destinations
- Create simple and intuitive navigation
- Improve the overall user experience

Tools Used

- Figma
- UI/UX Design
- Wireframing
- Prototyping

Key Screens

- Home Screen
- Explore Destinations
- Destination Details
- Booking Screen
